# AI-агент для автоматизации лидогенерации

AI-агент для Telegram, который обрабатывает обращения пользователей, определяет тип запроса и автоматически сохраняет контактные данные в Google Sheets.

## Tech Stack

- Coze
- Telegram Bot
- Workflow Automation
- Python
- Google Sheets
- Large Language Models (LLM)
- Intent Recognition
- Google Sheets API

## Основные возможности

- Определение типа пользовательского запроса.
- Сбор контактных данных в диалоге.
- Очистка технических данных из ответа LLM.
- Автоматическая запись лидов в Google Sheets.
- Сохранение контекста диалога.

## Как работает система

1. Пользователь отправляет сообщение в Telegram.
2. LLM определяет тип запроса.
3. При необходимости бот запрашивает недостающие контактные данные.
4. Python очищает ответ модели от технических метаданных.
5. Workflow записывает информацию в Google Sheets.

---

## Реализованные изменения

- **Intent Recognition:** настроена классификация пользовательских запросов на консультационные и регистрационные.
- **Очистка ответов LLM:** реализован Python-скрипт для удаления технических JSON-меток перед отправкой сообщения пользователю.
- **Интеграция с Google Sheets:** настроена автоматическая запись контактных данных в CRM-таблицу.
- **Контекст диалога:** бот сохраняет состояние диалога и запрашивает только отсутствующие данные.

---

## Очистка ответа LLM

Для удаления технических JSON-меток используется Python.
